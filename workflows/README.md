# Workflows

Обязательная часть ДЗ: минимум один workflow на каждого участника.

Каждый добавляет свой файл: `workflows/<github-login>-<название>.md`
(или папку скилла `workflows/<github-login>-<название>/`).

Формат свободный — скилл, хук, универсальный промпт, чек-лист процедуры. Требования:
- применим к вашей реальной повторяющейся задаче (не одноразовый);
- описано, как запускать и что получается на выходе;
- сам текст workflow приложен целиком.

Примеры: «прогон сборки и smoke-теста перед PR», «сбор ТЗ по шаблону из тезисов»,
«ревью чужого PR по чек-листу», «сборка PDF-отчёта из markdown».
