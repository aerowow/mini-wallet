# Mini Wallet

Учебное командное задание (ДЗ №2 курса по AI-агентам): мини-кошелёк на SwiftUI
с мок-данными. Три экрана — счета, перевод с идемпотентностью, история операций.
Без бэкенда и авторизации. Вся работа велась через AI-агентов, параллельными
субагентами, с PR-флоу и кросс-ревью. Все три экрана реализованы и смержены
в `main` (PR #1–#10).

## Как запустить
Минимальная версия — **iOS 26.0**: подойдёт любой Xcode с iOS 26 SDK,
конкретной 26.5 не требуется.

    git clone https://github.com/aerowow/mini-wallet.git
    cd mini-wallet
    open mini-wallet/mini-wallet.xcodeproj   # затем Cmd+R на любом симуляторе iPhone

Проверка сборки из терминала:

    xcodebuild -project mini-wallet/mini-wallet.xcodeproj -scheme mini-wallet \
      -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build

## Что умеет приложение
- **Счета** — сводный рублёвый баланс «Всего» (валютный счёт в сумму не входит),
  список счетов с масками и балансами, кнопка «Перевести»; пустое состояние,
  когда счетов нет.
- **Перевод** — между своими счетами в одной валюте: валидации (одинаковые
  счета, разные валюты, сумма ≤ 0, недостаточно средств), шит подтверждения,
  идемпотентность по UUID-ключу попытки — повтор с тем же ключом возвращает
  первоначальную операцию без повторного списания; защита от даблтапа; шиты
  успеха, повтора и ошибки с «Повторить» (прежний ключ). В DEBUG — переключатели
  «Ошибка выполнения» и «Симулировать повтор».
- **История** — read-only список операций, сгруппированный по дням
  («Сегодня»/«Вчера»/дата) с липкими заголовками; фильтры по типу
  (чипы «Все»/«Входящие»/«Исходящие»), счёту и периоду (шит с черновиком
  и «Применить»); поиск по комментарию и сумме; бейдж «Ошибка» у неуспешных;
  два пустых состояния.

Общее — в `Core`: модели (деньги только `Decimal`), `WalletStore`
(единый `@Observable`-стор с async `transfer` и реестром идемпотентности),
`MoneyFormatter` (формат «128 450,00 ₽»), `AppRouter` (программное переключение
вкладок), мок-данные (3 счёта, 7 операций с датами относительно текущего дня).

## Структура
- `mini-wallet/` — Xcode-проект; `mini-wallet/mini-wallet/Features/` — по папке на разработчика
- `mini-wallet/mini-wallet/Core/` — общий контракт: модели, `WalletStore`, `MoneyFormatter`, мок-данные, `AppRouter`. После мержа `core/shell` заморожен
- `docs/specs/` — ТЗ от PM (01-accounts, 02-transfer, 03-history), `docs/ONBOARDING.md` — онбординг участника
- `design/` — макеты (pen.dev): `accountsDesign.pdf`, `transferDesign.pdf`,
  `historyDesign.pdf` + промпт генерации `pen-dev-prompt.md`
- `sessions/` — журналы сессий с агентами (промпты дословно)
- `workflows/` — сохранённые workflow участников
- `REPORT.md` — отчёт: что делали, что не сработало, замеры
- `CLAUDE.md` — правила для агентов, `.github/pull_request_template.md` — шаблон PR
