# Журналы сессий

У каждого участника — своя папка: `sessions/<github-login>/`.

Один файл на рабочую сессию: `YYYY-MM-DD-<тема>.md`, например
`sessions/aerowow/2026-08-28-bootstrap.md`.

Внутри файла:
1. **Задача** — что хотели получить.
2. **Промпты дословно** — ключевые промпты как есть, без пересказа.
3. **Агенты** — что запускалось (субагенты, параллельно/последовательно).
4. **Решения** — что приняли и почему.
5. **Что не сработало** — тупики и откаты.

Чужие папки не редактируем. Перед коммитом проверить, что в лог не попали секреты.
