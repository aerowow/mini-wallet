## 4. Решения
- Смоук-тест выполнен через `xcrun simctl` (build → boot → install → launch →
  screenshot), MCP browser/panel-инструменты сознательно не использовались —
  по инструкции для этой сессии. UDID симулятора из брифа (`grep iPhone` по
  списку доступных устройств) указывал на симулятор без установленного
  рантайма для текущей схемы; выбран рабочий `iPhone 17` (UDID
  `40C2E62D-AB7D-42D0-9DCB-BBD8DD9A263C`, iOS 26.2) из списка валидных
  destinations схемы `mini-wallet`.
- Скриншот `tmp-tests/shell-smoke.png` подтверждает: таб-бар с тремя
  вкладками «Счета» / «Перевод» / «История», по умолчанию активна «Счета»
  (подсветка синим), на экране виден текст стаба «Счета — экран в
  разработке».
- Тап по вкладкам «Перевод» и «История» не выполнялся: `xcrun simctl` не
  предоставляет команды тапа по координатам (в отличие от MCP UI-инструментов
  или XCUITest), а бриф прямо разрешает в этом случае ограничиться
  визуальной проверкой дефолтного состояния как обязательным минимумом;
  переключение вкладок будет дополнительно упражняться при разработке
  экранов фич.
- README дополнен строкой про `mini-wallet/mini-wallet/Core/` в разделе
  «Структура»: перечислены `WalletStore`, `MoneyFormatter`, мок-данные,
  `AppRouter`, отмечена заморозка после мержа `core/shell`.
- Решения Задачи 6, зафиксированные для истории (эта сессия их не меняет,
  только проверяет результат): новый Tab API iOS 18+
  (`Tab(_:systemImage:value:)`) вместо устаревшего `.tabItem`; `@Bindable`-шэдоу
  для `selection` из `@Observable`-роутера (`AppRouter`); `ContentView.swift`
  удалён как неиспользуемый после перехода на `RootTabView`; разовая
  согласованная правка корня (`mini_walletApp.swift`) для подключения
  `WalletStore` + `AppRouter` — после мержа `core/shell` корень
  (`mini-wallet.xcodeproj`, точка входа приложения) больше никто из
  разработчиков фич не трогает.

## 5. Что не сработало
- Фолбэк-команда из брифа для выбора UDID симулятора
  (`xcrun simctl list devices available | grep iPhone | ... | head -1`)
  вернула первый попавшийся iPhone (`iPhone 14`), для которого у
  установленного Xcode не оказалось валидного destination для схемы
  `mini-wallet` (`xcodebuild: error: Unable to find a destination matching...`).
  Пришлось вручную сверить вывод ошибки со списком доступных destinations
  схемы и выбрать другой UDID (`iPhone 17`, iOS 26.2) — команду из брифа
  один в один выполнить не удалось.
- Смоук выполнялся полностью через `simctl` в headless-режиме — без ручного
  прогона человеком на экране; ручного визуального осмотра со стороны
  человека не было, только автоматический скриншот, который прикладывается
  к PR отдельно.
- В остальном (README, лог, коммит) тупиков не было.
