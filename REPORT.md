## PM — ТЗ и PDF
### Что делал / какие агенты и субагенты
Три ТЗ (`docs/specs/01-accounts.md`, `02-transfer.md`, `03-history.md`) собраны из
`design/pen-dev-prompt.md` по шаблону `docs/specs/TEMPLATE.md`, критерии приёмки — в форме
«дано/когда/тогда». Главная сессия Claude Code писала черновики; по каждому ТЗ отдельно
запрашивался разбор «что дословно из источника / что добавлено для ясности / что агент
решил сам» — третий список разбирался PM по пунктам, решения принимал человек.
Ревью — три независимых read-only субагента, по одному на файл, каждому только его ТЗ,
шаблон, `CLAUDE.md`, дизайн-промпт и ответы разработчиков по его разделу; выводы друг
друга агенты не видели. Отчёты сведены, дубли сняты, замечания разложены на критичные,
средние и необязательные, отдельно выписаны отклонённые. Workflow —
`workflows/jwynana-spec-from-design.md`, лог — `sessions/jwynana/2026-08-28-specs.md`.

### Что не сработало
- Агент писал ТЗ, принимая продуктовые решения за PM: только по экрану «Счета»
  таких самостоятельных допущений набралось 13 — от «приложение открывается на этой
  вкладке» до придуманного текста сноски. Помог явный разбор по трём спискам;
  без него они бы ушли в разработку как согласованные требования.
- Первые версии ТЗ фиксировали техническую реализацию (сигнатуры методов, имена типов,
  где вычисляется сводный баланс). Пришлось переписывать разделы «Данные из общего
  контракта» в «данные и возможности» + «вопросы к разработчикам».
- Три вызова субагентов ушли в двух сообщениях, поэтому прогон оказался частично
  последовательным: параллельно пересеклись только Transfer и History. Параллельность
  даёт батч в одном сообщении, а не порядок вызовов.
- Субагенты предлагали упростить осознанные решения PM (правила поиска, механизмы
  сброса фильтров, счётчик) — такие замечания отклонены с обоснованием.
- Зато ревью нашло реальную дыру: при принятой механике ключа состояние
  «Перевод уже выполнен» было недостижимо из UI, то есть идемпотентность —
  главная механика ДЗ — не воспроизводилась ни одним действием пользователя.
